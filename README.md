# Personal Expense Analytics Dashboard

A desktop application built using Python, Tkinter, MySQL, and Matplotlib to manage personal expenses and visualize spending patterns.

## About the Project

The Personal Expense Analytics Dashboard helps users record, manage, and analyze their expenses through a graphical user interface. It displays expense summaries, charts, and insights to make spending patterns easier to understand.

This project was developed as part of my programming and project-based learning journey.

## Features

- Add new expense records
- Update and delete existing expenses
- Filter expenses by month, category, and payment mode
- View total expenses and average transaction amount
- Identify the highest expense and top spending category
- Visualize category-wise spending with pie charts
- Analyze spending with bar charts
- View daily expense trends
- Analyze payment modes using a doughnut chart
- Display the top 5 expenses
- View expense insights
- Store expense records in a MySQL database

## Technologies Used

- **Python** — Application logic
- **Tkinter** — Graphical user interface
- **MySQL** — Database management
- **Matplotlib** — Data visualization
- **mysql-connector-python** — Python–MySQL connectivity

## Requirements

- Python 3
- MySQL Server
- Python packages: `mysql-connector-python` and `mat
